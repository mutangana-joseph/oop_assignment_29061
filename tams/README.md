# Tax Administration Management System (TAMS)

## Project Description

The Tax Administration Management System (TAMS) is a Java console-based application developed for academic purposes. It simulates basic tax administration activities using fictional tax rules and simplified procedures.

The system demonstrates how taxpayers can be registered, tax obligations created, declarations submitted, assessments made, payments recorded, penalties calculated, refunds requested, and tax clearance managed.

## Project Objectives

- Demonstrate Object-Oriented Programming (OOP) concepts in Java.
- Apply inheritance, abstraction, interfaces, encapsulation and polymorphism.
- Practise data validation and exception handling.
- Demonstrate relationships between different tax administration records.
- Use arrays to store and manage records.

## Technologies Used

- Java
- Java OOP concepts
- `BigDecimal` for monetary calculations
- `LocalDate` for date handling
- Fixed-size arrays for record storage

## Important Note

This project is strictly an academic simulation. All tax rates, calculations, penalties and administrative procedures are fictional and are not intended to represent actual Rwandan tax laws or official tax administration procedures.
